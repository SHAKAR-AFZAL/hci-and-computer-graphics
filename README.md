# Human Computer Interaction & Computer Graphics Lab

_Practical labs (Inlab & PostLab) exercises covering Human Computer Interaction (HCI) and Computer Graphics, focusing on user centered design, usability, graphics programming, visualization, and algorithm implementation._

---

## Overview

This repository contains my laboratory work for **Human-Computer Interaction (HCI)** and **Computer Graphics** completed during the BS Computer Science program. It showcases practical implementations of UI/UX principles, usability evaluation, graphics algorithms, and interactive application development through hands-on assignments.

---

## Topics Covered

### Human-Computer Interaction (HCI)
- User-Centered Design (UCD)
- User Interface (UI) Design
- User Experience (UX)
- Usability Principles
- Heuristic Evaluation
- Accessibility
- Wireframing & Prototyping

### Computer Graphics
- Graphics Fundamentals
- Line & Circle Drawing Algorithms
- 2D & 3D Transformations
- Clipping Algorithms
- Viewing & Projection
- Animation Basics
- OpenGL Programming
